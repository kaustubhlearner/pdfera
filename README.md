# PDFera

A free-first Smallpdf-style PDF toolkit built with Next.js, TypeScript, Tailwind CSS and pdf-lib.

## Current MVP

- Merge multiple PDFs in the browser
- Extract page 1 from a PDF
- No database
- No permanent file storage

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Roadmap

- Split by page range
- Reorder/delete pages
- JPG to PDF
- PDF to JPG
- Compress PDF
- Drag and drop
- Better mobile UI
- Privacy and file-size messaging
